## Notes

- QPS and p50/p99 are from single-query (non-batched) search, so every engine is measured the same way; batched search (`search(xq, k)` over all queries at once) would raise QPS further for every engine.
- ELIPS and faiss both use the FAISS-style Index API (`IndexFlat`/`IndexIVFFlat`, `metric="l2"`); labels are row indices, so recall is measured against the same numpy L2 ground truth.
- `ELIPS bf_knn (metal)` is the Apple-GPU exact brute-force path (`elips.bf_knn(..., device="metal")`), no index build.
